TOCTOU Race Condition on Balance & Credit Deduction (ID: CONC-001)
P0 Critical
📍 Bagian yang Kena Audit (Affected Scope)
File & Rute: app/api/wallet/deduct/route.ts#L22-L38

Bukti Audit: Pola const user = await db.user.findUnique(); if (user.credits >= amount) await db.user.update({...}) memungkinkan dua request bersamaan membaca saldo yang sama dan sama-sama berhasil, menghasilkan saldo minus (overdraft).

🛠️ Cara Memperbaikinya (Remediation Instructions)
1. Hapus pembacaan saldo ke memori JavaScript.
2. Gunakan query atomic bersyarat:
UPDATE users SET credits = credits - :amount WHERE id = :id AND credits >= :amount RETURNING credits;
3. Jika baris yang terupdate = 0, kembalikan response 409 Conflict (saldo tidak mencukupi).
🤖 AI Agent Fix Prompt 
Refactor app/api/wallet/deduct/route.ts to eliminate read-modify-write race conditions. Use an atomic conditional SQL query: UPDATE users SET credits = credits - $1 WHERE id = $2 AND credits >= $1 RETURNING credits. Return HTTP 409 if no rows were updated. Add a concurrency test with 5 parallel requests.
